# 实例模板

本目录维护紫金规范的**实例模板**：面向工程实践的细则版规范，细则的权威形态；作为本体项目的正式组成内容单独维护，随规范版本一并发布。

实例模板即实例内容的完整来源（见 [../规范正文/04-初始化规范.md](../规范正文/04-初始化规范.md)），按实例结构分设两个子文件夹，初始化时整体复制到项目根：

- `purplegold/`（静态规则层）：
  - `RULES.md`：蒸馏规则，AI 的操作手册；
  - `templates/`：合金文档模板（含根模块合金文档模板）；
  - `scripts/`：对齐脚本与校验脚本（Python 3）；
  - `脊椎规范/`：脊椎流程各阶段的规范，每阶段一个文件夹（`S01-需求确认/` 式命名，各含阶段规范文档 `规范.md`）；
  - `肋骨规范/`：各肋骨规范的定义，每份规范一个独立文件夹（内含 `规范.md`，可携带参数文件等附件）。
- `紫金产物/`（动态文档层骨架）：
  - `规范反馈.md` 空骨架：规范使用反馈（实例到本体的反馈通道）；
  - `脊椎产物/`：各阶段的产出文档，每阶段一个文件夹；初始化时为空，阶段文件夹随首次产出创建；
  - `肋骨产物/`：各肋骨规范的执行产出，每份规范一个独立文件夹；初始化时仅含预置的 `AB03-项目最新状态/`（三份状态文档骨架：脊椎流程进展、肋骨规范进展、外骨骼实现情况），其余规范文件夹随首次产出创建。

`VERSION` 不含在模板内，初始化时在 `purplegold/VERSION` 写入当前规范版本号。`脊椎产物/` 初始化时为空，以一个 `.gitkeep` 占位。

当前对应规范版本见 `../VERSION`；各版本变更见 `../changelog/`。
