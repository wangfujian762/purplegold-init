# 阶段 6 · 制定开发计划

> 定位：将功能与架构分解为可执行任务，确定执行顺序、完成判据与分工。
> 本文件是脊椎流程阶段 6 的蒸馏规范；产出文档写入 `紫金产物/脊椎产物/S06-制定开发计划/`。

## 约束

- **测试先行（TDD）**：任务规划遵循测试先行——任务分解清单中的每个实现任务须包含先行编写对应测试的安排；任务完成判据中，实现任务的判据须包含对应测试通过。
- **输入依据**：本阶段的输入为阶段 S01～S05 的产物；禁止以肋骨规范 M04-工作量评估的产物作为本阶段工作的输入依据（M04 仅供报价与人类工程师的宏观排期参考）。

## 产物清单

产物按清单顺序产出；落在本阶段产物文件夹内的产物（文件或文件夹）以 `序号-名称` 命名。

| # | 产物 | 格式 | 内容说明 |
|---|---|---|---|
| 01 | 任务分解清单 | Markdown | 任务分解到可执行粒度，标注任务间的依赖关系；每个实现任务包含先行编写对应测试的安排（见本节约束） |
| 02 | 任务顺序与里程碑 | Markdown | 任务的执行顺序、里程碑节点（可与 01 合并为一份文档） |
| 03 | 任务完成判据 | Markdown | 每个任务的可检验完成判据；实现任务的判据须包含对应测试通过；阶段 7 的"完成"登记与 AB03-项目最新状态的进展更新以此为依据 |
| 04 | 分工说明 | Markdown | 各任务由人还是 AI 执行、需要人工介入的节点 |
| 05 | 风险清单（可选） | Markdown | 已识别风险与应对方式；视项目规模决定是否产出 |
