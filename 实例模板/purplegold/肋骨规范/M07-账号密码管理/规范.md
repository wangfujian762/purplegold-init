# 肋骨规范 · M07-账号密码管理

> 触发时机：无自动触发时机——由人类工程师手动启用；新增或变更账号时随时登记。
> 执行产出写入 `紫金产物/肋骨产物/M07-账号密码管理/`。

## 定位

集中管理项目中所有正式账号与测试账号的账号和密码，防止遗忘。

## 规则

- 产物文件夹下维护账号清单，逐项登记：账号名、用途（正式/测试）、所属服务、密码、注册信息、备注。
- 密码本体以明文记录在本规范产物中，随项目 Git 仓库入库管理。适用前提：项目仓库为私有仓库；若仓库存在公开的可能，人类工程师须改用其他保管方式，不适用本规范。
- 与脊椎流程的边界：阶段 S05 的外部服务接入清单只记录凭据管理方式，不记录秘密本身；实际账号与密码登记在本规范产物中。
